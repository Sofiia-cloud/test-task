# ЭкоРеестр

Демо SPA для тестового задания: административная панель учёта граждан и обращений. Интерфейс сделан на React + TypeScript, с адаптивной вёрсткой и демонстрационными данными.

## Запуск

```bash
npm install
npm run dev
```

Для production-сборки: `npm run build`, для локального просмотра сборки: `npm run preview`.

## Что реализовано

- Дашборд с показателями, графиком обращений, категориями граждан, активностью и задачами.
- Картотека со 100 000 детерминированно генерируемых демо-записей, поиском, быстрыми фильтрами, точным количеством совпадений, постраничной навигацией и выбором размера страницы. Создание записей позволяет превысить отметку в 100 000.
- Карточка выбранного гражданина с 15 разделами и более чем 150 параметрами. Значения полей редактируются и сохраняются в локальном хранилище браузера.
- 20 связанных таблиц с разными колонками и примерами данных, добавлением, редактированием и удалением строк.
- Дашборд со сводными показателями, возрастной диаграммой и распределением по категориям, пересчитываемыми по картотеке.
- Форма добавления гражданина и экспорт всего отфильтрованного набора в CSV.
- Адаптация для узких экранов.
